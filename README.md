# QuickGist

*QuickGist* es una herramienta web simple, rápida y gratuita para generar resúmenes de texto. Está diseñada para ayudarte a obtener una versión corta y clara de textos largos con un solo clic.

## Características

Interfaz moderna y responsive
Pegá cualquier texto y obtené un resumen instantáneo
100% frontend, sin necesidad de iniciar sesión
Funciona en computadoras y dispositivos móviles

## Demo

Podés probar la aplicación online acá:  
[https://tu-usuario.github.io/quickgist](https://tu-usuario.github.io/quickgist)  
(Reemplazá "tu-usuario" por tu nombre real de GitHub)

## Cómo usar

Pegá el texto que querés resumir.
Hacé clic en el botón “Resumir”.
¡Listo! El resumen aparecerá en pantalla.
